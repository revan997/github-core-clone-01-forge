A standalone GitHub-compatible git forge in one process: git smart HTTP (upload-pack v2 + v0, receive-pack v0), the REST v3 API, GraphQL v4, and MCP — all served from its own in-memory store. Node standard library only; nothing is installed, no git binary, no outside service.

## Run it

```sh
node --experimental-strip-types main.ts
```
